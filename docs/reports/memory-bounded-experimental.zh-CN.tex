\section*{摘要}
教师评分即使只返回紧凑结果，也可能先生成更大的“投影行 × 词表”logits 张量。本项目将 LM Head 的行分块读出接入固定版本的 verl \code{TeacherFSDPWorker}，保留学生候选 ID 的全词表归一化 logprob 和教师自身的有序 Top-$K$，同时经由正常 FSDP2 forward 执行，保留共享权重与模块 hooks。

在单张 RTX 5070 Laptop GPU 上，Qwen2.5-0.5B-Instruct 使用 BF16、$K=32$、每块 256 行、CPU offload 和 allocator fraction 0.50 时，$N=8192$ 的 Worker 对照使 peak allocated 降低 81.05\%；262,144 个候选分数和 8,192 行有序 Top-$K$ 均逐值一致。独立的直接 Worker 到 Student 实验还匹配了固定损失、所检梯度和一次受限 RMSNorm 更新。该结果属于单 GPU 实验性优化，时延测量用于描述。

\section{问题与评分契约}
令 $N$ 为投影模型行数、$V$ 为词表大小、$K$ 为每行候选数。稠密语言模型输出头即使最终只返回 $O(NK)$ 个值与 ID，也可能先分配 $N\times V$ logits。仅缩小响应并不能限制中间读出分配。

对于隐藏状态行 $h_t$、输出头权重 $W$、偏置 $b$ 和候选 $i$，所需的全词表归一化分数为
\begin{equation}
z_{t,i}=h_t^{\mathsf T}W_i+b_i,\qquad
\log p_{t,i}=z_{t,i}-\log\!\sum_{j\in\mathcal V}e^{z_{t,j}}.
\end{equation}
归一化分母覆盖完整词表。Worker 还返回教师自身的有序 Top-$K$ ID，因此仅投影学生候选 logits 通常无法重建完整接口。候选 ID 可以重复，其顺序和重复次数、有效行顺序及嵌套 offset 都属于输出契约。

行分块和 selected-logit 原语均有已有工作；本项目的工程重点是将它们接入固定 Worker、FSDP 生命周期与下游评分契约。\cite{verl6920pinned,indexedlogits,sglang38119}

\section{实现方法}
\subsection{FSDP 与输出头生命周期}
适配器在普通 \code{Qwen2ForCausalLM} 被 FSDP 封装之前安装，保留参数对象及共享的输入／输出权重。请求通过正常的外层 FSDP 模块调用进入；主干网络与最终归一化执行一次，然后将隐藏状态按块送入 \code{lm_head} 模块。这样既保留输出头的前后 hooks，也保留外层 FSDP forward 边界。

每块 logits 转为 FP32，计算 log-sum-exp 和候选 gather；所选分数转回 logits dtype，并保留教师 Top-$K$ ID。当前块处理完成后丢弃。$B<N$ 时，同时存活的 logits 块随 $BV$ 而非 $NV$ 扩展；紧凑输出仍随 $NK$ 扩展，模型、主干网络和 FSDP 分配依然存在。全词表投影计算并未被消除。

\subsection{分块选择与稠密回退}
可选的输出头预算在 forward 前确定分块大小。令 $s$ 为 logits 每元素字节数，$H$ 为请求的读出预算，$B_{\mathrm{requested}}$ 为请求的行数上限（省略时取 $N$），实现中的估算为
\begin{align}
M_c &= NK(s+8), & m_r &= \left\lceil1.25\,[V(s+8)+24K]\right\rceil,\\
B &= \min\!\left(N,B_{\mathrm{requested}},\left\lfloor\frac{H-M_c}{m_r}\right\rfloor\right).
\end{align}
估算包含紧凑输出、logits 块、FP32 工作张量和 Top-$K$ 开销，不覆盖全部模型分配、后端工作区或内存碎片。未设置显式预算且所选分块覆盖全部行时，集成路径使用原生稠密 forward；显式预算不会被静默替换为这一回退。

\subsection{填充与消费者对齐}
候选 ID 使用准备好的 attention mask 散射到填充后的模型行，返回时恢复有效行的原始顺序。适配器不对这些 ID 额外施加因果位移。消费者实验在计算聚合损失和诊断指标前，将 response mask 对齐到预测位置。

\section{实验设置}
最终对照使用 Qwen2.5-0.5B-Instruct、BF16 和 SDPA，运行于单张 RTX 5070 Laptop GPU；软件为 PyTorch 2.14.1+cu130，使用 FSDP2 CPU offload、$K=32$、$B=256$ 和 PyTorch allocator fraction 0.50。文本及候选 ID 均为合成数据。每个长度按 Dense--Chunked--Chunked--Dense 顺序运行四个独立进程；每进程预热一次、测量五次。下表中每个模式的 p50/p95 汇总十次测量。

最终矩阵与分块大小实验保存的 96 份紧凑输出均已重新读取，并与同长度 Dense 参考比较。$N=8192$ 时，262,144 个候选 logprob 和 8,192 行有序教师 Top-$K$ 均逐值一致；比较还检查输出身份、形状和 offset。

\section{当前范围与后续工作}
已测路径覆盖单 GPU FSDP2 下使用共享输出头的 Qwen2；消费者实验是受限参数更新。后续可扩展 packed 变长输入、模型覆盖、FSDP1 与多 GPU／张量并行验证，并接入端到端 RL Trainer。早期仅计算 selected logits 的融合方案对完整教师契约仍为 NO-GO；历史结果保留了相应负结果。

\section{复现}
实验评分基线为 \href{https://github.com/yu830/rl-posttrain-sparse-scoring/commit/ad395e94923bcf65fff4bc1eeb2e0e1505fd4f91}{\code{ad395e9}}。Worker 补丁基于 verl \code{87cd055e872f9fdd7b976fcd797a0934b6dba265}，固定 Qwen 模型版本为 \code{7ae557604adf67be50417f59c2c2f167def9a775}。Linux／Python 3.12 的独立 Worker 锁文件固定了 105 项依赖。\href{https://github.com/yu830/rl-posttrain-sparse-scoring/blob/main/docs/experimental-reproduction.md}{复现指南}列出环境、模型哈希和命令；\href{https://github.com/yu830/rl-posttrain-sparse-scoring/blob/main/results/worker-evidence-manifest.json}{证据清单}通过 SHA-256 关联归档测量。

展示版本 \code{c0f019e} 的 \href{https://github.com/yu830/rl-posttrain-sparse-scoring/actions/runs/41170230693}{GitHub CPU 回归运行}报告 171 项通过、2 项取消选择、零跳过。该任务检查 CPU 回归和补丁适用性；GPU Worker 测量是独立实验。

\section{结论}
将行分块边界前移至 LM Head，使该路径在保留紧凑评分输出的同时降低了读出期间的分配峰值。单 GPU 实测、逐值输出对照和受限 Student 更新，为进一步集成提供了具体依据。
