# Document build environment

The delivered PDFs and diagrams were built with the exact versions and SHA-256 fingerprints recorded in [build-environment.lock.json](./build-environment.lock.json). The snapshot records Ubuntu 24.04.3 x86-64, Python 3.12.14, Pillow 12.3.0, TeX Live 2023/Debian, Poppler 26.05.0, the relevant TeX package files, and the bundled font hash. Install the Python package specified in [requirements-docs.txt](./requirements-docs.txt); matching the recorded TeX and Poppler toolchain requires installing the listed versions separately.

The lock is an environment fingerprint, not an automatically provisioned container. A different system or dependency version may still build correctly, but its output must be independently checked. Compiler metadata such as PDF creation time can change generated bytes even with the same source; the delivery hashes identify this specific build, not a promise of bit-for-bit reproducibility.

The [font notes](../assets/fonts/README.md) describe the licensed bundled subset and using a full font when adding characters. Run `bash scripts/build_assets.sh` followed by `python3 scripts/verify_assets.py` from the repository root.

To require the recorded Python/Pillow versions, executable hashes and TeX package hashes, run `python3 scripts/verify_assets.py --locked-environment`. Ordinary asset verification does not require a byte-identical toolchain.
