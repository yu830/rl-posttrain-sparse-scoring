# 基准测试方法

以下实验均尚未执行。本文描述未来可复现的比较方法，不构成性能或训练收益证据。

1. 明确真实消费者的损失、候选生成时序、策略/模型/分词器版本、位置、掩码和输出归一化；保留 next-token 位移。条件 logprob 与全词表 logprob 是不同契约。
2. 在相同条件目标下比较稠密投影加 gather、分块稠密、eager 索引 gather，以及兼容时的已有 IndexedLogits 基线。原生全归一化评分只作为背景，不用于同目标加速比。相应计时边界需计入候选移动、校验和回退工作。
3. 建立 CPU FP64 参考值与学生梯度；检查单候选和全词表支持、排列、重复/非法 ID、变长掩码、未选 logits 及因果对齐。在比较前确定各精度容差，并记录不支持的模型输出头。
4. 冻结代码、环境、模型、分词器、硬件、轨迹、并发和负载维度；分开调参与评估。报告排除或 OOM 的组合及回退次数。服务收益需要真实候选轨迹，并区分教师回放与真实训练。
5. 随机成对 A/B 前先做 A/A 对照。报告噪声、请求 p50/p95 延迟、内核延迟、吞吐、已分配/保留显存、负载字节数、数值误差、失败与负结果。主要计时与分析器分开；对照不稳定时应判为无结论。

定义、解析示例及局限见[中文报告](./reports/technical-report.zh-CN.pdf)。
